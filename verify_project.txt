# ========================================
# EXPECTED WORKFLOW TIMELINE
# ========================================

# When you trigger the DAG:
#
# 1. [0-10s] truncate_orders_live - Clears Postgres table
# 2. [10s-2min] produce_csv_to_kafka - Sends CSV to Kafka
# 3. [10s-1min] spark_oltp_streaming_to_postgres - Streams to Postgres (parallel with producer)
# 4. [2-3min] kafka_to_bronze_csv - Reads all Kafka messages to HDFS Bronze
# 5. [3-4min] bronze_to_silver - Transforms CSV to Parquet (Silver layer)
# 6. [4-5min] silver_to_gold - Aggregates data (Gold layer)
#
# Total time: ~5-7 minutes for full pipeline
